разработай сервис для управления школьной музыкой

стек: всё поднимается через docker
фронтенд на react typescript с tailwind css
backend на python fastapi с sqlalchemy и pydantic для миграция
база данных: sqlite

по итогу должен быть один порт, торчащий локально на 127.0.0.1 сервера, откуда его будет брать caddy и раздавать в веб

функционал:
при входе 3 кнопки:
1. создать событие
2. войти в событие
3. войти в событие как администратор

1. открывает попап, где можно указать дату события и название, также загрузить расписание звонков и музыку. после создания события появляется 6 значный код из цифр, который действует в течение недели, а также 16 символьный пароль для входа в событие как администратор. далее открывается окно управления событием

2. открывает попап ввода 6 значного кода. после успешного ввода кода идёт подключение к событию и открывается окно event slave (не знаю как по русски)

3. после ввода пароля открывается окно управления событием

ОКНО управления событием:
позволяет загрузить/догрузить музыку и вообще управлять порядком (можно перемешать), можно удалять треки.
треки можно зациклить и вообще должна быть гибкая система управления очередью
управление расписанием звонков (задаются перемены) в которые будет играть музыка. расписание можно экспортировать/импортировать. формат: txt файл со строками формата HH:MM-HH:MM
также есть плеер, где видно, что сейчас играет, можно ставить паузу и переключать треки.
также должна быть возможность перегенерировать 6-значный код (уже привязанные устройства не удаляются)
и должен быть список устройств (браузеров), которые вошли в событие.
должна быть возможность управлять звуком на админcком устройстве (можно слышать/не слышать музыку)

всё хранится на сервере, админское устройство не должно быть активно для работы системы

ОКНО event slave:
плеер без возможности управлять воспроизведением. треки берутся с сервера и воспроизводятся одновременно на всех устройствах в нужное время. должен быть ползунок громкости и возможность выбора устройства вывода, а также кнопка выхода из события
