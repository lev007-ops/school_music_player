# Школьная музыка

Автор: Барях Лев, ученик 10А класса школы № 9 г. Пермь.

Сервис для музыки на переменах: администратор загружает треки и расписание, а все подключённые
браузеры играют музыку синхронно в нужное время. Сервер сам переключает треки по расписанию,
поэтому админское устройство может быть выключено.

## Запуск

```bash
docker compose up -d --build
```

Сервис слушает `127.0.0.1:8080` (наружу не публикуется). Пример для Caddy — в `Caddyfile.example`:

```
music.example.ru {
	reverse_proxy 127.0.0.1:8080
}
```

HTTPS обязателен для выбора устройства вывода и для удержания экрана включённым. Caddy выдаёт
сертификат сам.

Данные (SQLite и музыка) хранятся в `./data`. Миграции Alembic применяются при старте контейнера.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `APP_PORT` | `8080` | Локальный порт на 127.0.0.1 |
| `APP_TIMEZONE` | `Europe/Moscow` | Пояс события, если браузер создателя не передал свой |
| `APP_MAX_UPLOAD_MB` | `300` | Максимальный размер одного аудиофайла |

## Как это работает

- **Событие**: 6-значный код для устройств (действует 7 дней, можно перегенерировать, уже подключённые
  устройства при этом остаются) и 16-символьный пароль администратора (показывается один раз).
- **Часовой пояс** берётся из браузера создателя события и меняется в настройках события.
- **Автоудаление**: событие и его музыка удаляются, если в него никто не заходил 7 дней. Пока к событию
  подключено хоть одно устройство, оно считается активным.
- **Режимы**: «По расписанию» (музыка звучит только в перемены в дату события), «Сейчас»
  (игнорировать расписание), «Тишина».
- **Очередь**: перетаскивание, перемешивание, «играть сейчас», «играть следующим», зацикливание
  трека, пропуск трека без удаления. Повтор: очередь по кругу / один трек / без повтора.
- После конца перемены следующая начнётся со следующего трека. За 3 секунды до конца перемены
  музыка плавно затихает.
- **Синхронизация**: сервер хранит момент старта текущего трека. Клиенты оценивают смещение часов
  по пингам через WebSocket и подстраивают позицию: мелкие расхождения — скоростью воспроизведения,
  крупные — перемоткой. Текущий и следующий треки скачиваются в память заранее.
- **Формат расписания** (импорт/экспорт): `.txt`, по строке `HH:MM-HH:MM` на перемену. Пустые строки
  и строки с `#` игнорируются.

Поддерживаемые форматы аудио: mp3, m4a, aac, ogg, opus, wav, flac, webm.

## Ограничения

- Выбор устройства вывода работает в Chrome, Edge и Firefox. В Safari используется системное устройство.
- На iOS громкость регулируется только кнопками устройства.
- Браузеры могут блокировать автозапуск звука после перезагрузки страницы. Тогда плеер покажет кнопку
  «Включить звук», а администратор увидит это в списке устройств.
- Нужен ровно один процесс uvicorn: подключения и цикл плеера живут в памяти.

## Разработка

```bash
cd backend && uv sync && APP_DATA_DIR=../data uv run alembic upgrade head \
  && APP_DATA_DIR=../data uv run uvicorn app.main:app --reload
cd frontend && npm install && npm run dev   # проксирует /api на :8000
```
